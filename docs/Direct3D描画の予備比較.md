# DXVK と WineD3D の Direct3D 描画予備比較

## 目的と制約

DXVK を使わない選択肢を評価する準備として、無料の自作 Windows x86-64 合成試験 `tools/graphics-benchmark/d3d-smoke.cpp` と、DXVK／WineD3D を交互に実行する CI を用意した。ゲームや標準ベンチマークではなく、代表的なゲーム負荷を再現していない。**結果は Android・GameNative・Pixel 9a の GPU 性能、FPS、発熱、共有メモリ使用量を示さない。**

環境は GitHub Actions `ubuntu-24.04` x86-64、Wine、DXVK 2.6.1 と Wine 内蔵 WineD3D、Vulkan lavapipe と OpenGL llvmpipe のソフトウェア描画、Xorg dummy 画面。x86-64 の Wine 上で実行し、FEX／Box64 は使用していない。実際のソフトウェア GPU、Wine／コンパイラーのバージョン、DXVK 配布物と EXE の SHA-256 は実行成果物 `environment.txt` に保存（Actions の成果物は14日間）。取得した DXVK は公式 GitHub リリースのバージョンを固定し、ハッシュを記録しているが、独立した公式チェックサムでの照合は実施していない。

同じ Windows 実行ファイルで各 API の描画を実行し、320×240、三角形の描画、各プロセスの30フレームのウォームアップ後に180フレームを計測。最後の1フレームで画像の1ピクセルを読み戻し、期待する赤色を確認する。各方式は別 Wine プレフィックスと DLL ディレクトリを使い、事前実行で d3d9／d3d11／dxgi DLL の種類を Wine のログで確認した。各 API ごとに DXVK → WineD3D の順で交互に4回実行した。これは1ピクセルの確認にすぎず、画像全体の同一性、ゲーム互換性やすべての描画機能の正しさを保証しない。Direct3D 9 と11は別実装であり、API 間の数値を直接比較しない。

## 結果

[実行 43544531253](https://github.com/Python121212/My-GameNative-v1/actions/runs/43544531253) は全16試行と1ピクセルの検査が成功。FPS は180フレームを描画・表示し、最後に1回読み戻す時間から計算した算術平均で、ウォームアップとプロセス初期化は含まない。単純な負荷のため数値は高く、ソフトウェア実装・共有 runner・Xorg・キャッシュなどに依存する。

| API | 方式 | 1回目 | 2回目 | 3回目 | 4回目 | 平均 FPS |
|---|---|---:|---:|---:|---:|---:|
| D3D9 | DXVK | 1636.996 | 1625.831 | 1616.397 | 1612.021 | 1622.811 |
| D3D9 | WineD3D | 3105.703 | 2986.719 | 3038.513 | 2977.510 | 3027.111 |
| D3D11 | DXVK | 1683.341 | 1677.824 | 1654.876 | 1656.682 | 1668.181 |
| D3D11 | WineD3D | 2162.282 | 2148.569 | 2140.892 | 2150.759 | 2150.626 |

この限定条件では WineD3D の平均が高かったが、方式の一般的な優劣や Android 実機での選択を決める根拠にはならない。温度・フレーム時間の分布・GPU メモリは測っていない。毎回 DXVK から始まる順番の偏りも残る。各試行の時間とログは Actions 成果物にある。

最初の試験は lavapipe の ICD 名の違いで停止。次に Wine のシェーダーコンパイル時にアサーション、修正後は Xvfb 使用時に DXVK の D3D11 でゼロ除算が発生した。画面のリフレッシュレートを指定しても再現したが、Xorg dummy のモード設定後は完走した。根本原因は未確定で、Xvfb の不具合と断定しない。失敗した試験の数値は採用していない。

## 次の検証

- GameNative の隔離されたテスト環境で、同一のベンチマーク・Wine・変換器・解像度・キャッシュ条件を固定し、DXVK と WineD3D のロードおよび描画全体を確認して各4回比較する。利用できる場合は温度・フレーム時間とメモリも測る。既存ゲームデータや APK は削除しない。
- WineD3D の出力先も確認する。OpenGL の後段に Zink などがあれば Vulkan に変換されるため、WineD3D 選択だけで Vulkan を使っていないとは言えない。
- 無料の実際のゲームに進む場合は再現可能な場面・正確性を確認し、測定順やウォームアップを揃える。SuperTuxKart は事前に定めた CPU 比較・改善確認後に行う。
