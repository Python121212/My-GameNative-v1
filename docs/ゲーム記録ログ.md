# ゲーム記録ログ

設定の「デバッグ」で「ゲーム記録ログ」をオンにしてからゲーム画面を開くと記録が始まる。初期設定はオフ。設定を変更した場合は、次にゲーム画面を開くときから反映する。自動アップロードはしない。

同じ設定画面の「最新の記録ログを保存」で保存先を選ぶと、最新の1セッションを ZIP に保存する。各行の日時は端末の現地時刻と UTC オフセットを、秒まで記録する。端末の時計が正しくなければ日時も正しくない。

| ファイル | 記録内容・限界 |
|---|---|
| `temperature.txt` | 約5秒ごとのバッテリー温度。CPU、GPU、表面温度ではない。取得不可の場合はその旨を記録する。 |
| `fps.txt` | 約5秒ごとの GameNative 表示フレームからの推定値。ゲーム内部 FPS とは限らず、フレーム更新がない場合は取得不可。 |
| `network.txt` | 約5秒ごとの Android 接続種別とインターネット検証状態。Steam 接続・通信量・遅延・パケットの記録ではない。 |
| `launch.txt` | ゲーム画面の開始／終了、環境初期化、ゲストプロセス終了を記録。画面を開いたことや環境初期化はゲーム起動成功の証明ではない。異常終了の詳細や認証情報は記録しない。 |

通信先、通信内容、Steam アカウント・トークン、ゲームファイルや自由形式のエラー本文は意図的に記録しない。時間や端末の利用状況などは個人情報になり得るので、ZIP の共有先には注意する。保存先はアプリ内の非公開領域で、アプリ削除時には失われる。記録中に OS がアプリを強制終了した場合、終了行が残らないことがある。各ファイル最大1 MiB、最大20セッションで新規記録を停止する。設定画面で全記録を確認付きで削除でき、ゲームデータや書き出し済み ZIP は削除しない。最新以外の記録を個別に取り出す機能はないため、必要な結果は次の記録を始める前に書き出す。

FPS と温度はハードウェアや描画経路によっては取得できない。記録による負荷もあり、性能比較では記録オン／オフの影響を確認する。Pixel 9a 実機と実ゲーム、Steam・マルチプレイの動作は未検証。
