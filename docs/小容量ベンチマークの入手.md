# 小容量の測定用ソフトを入手する

## 操作

GameNative の **設定 → デバッグ** に追加した「CPU 測定用：7-Zip」「描画測定用：AIO Graphics Test」を選択し、説明を読んで「ブラウザで取得」を押す。ユーザーのブラウザが公式 GitHub の固定バージョンのファイルを開く。通信・ダウンロード先の選択・進捗・失敗の通知はブラウザ側で行う。ブラウザがない場合はエラー表示する。GameNative は自動ダウンロード、展開、インストール、実行、結果収集、ゲームの送信を行わない。配布元はアクセス情報を受け取る場合がある。両ソフトのライセンスは各公式配布元で確認する。

どちらも **Windows x64 向け**であり、Android アプリ（APK）ではない。ダウンロードしたファイルを専用フォルダに置き、ライブラリの「＋」からそのフォルダを追加して実行する。モダン版ではフォルダがアプリ領域にコピーされるため、空き容量はダウンロードサイズ以上必要。インポート時の元ファイル削除オプションは選ばない。既存ゲーム・セーブのあるフォルダは選ばない。

## CPU：7-Zip 26.06

- [作者の公式リリース](https://github.com/ip7z/7zip/releases/tag/26.06) の Windows x64 インストーラー `7z2606-x64.exe`：1,659,704 バイト（約1.6 MB、展開後は別）。SHA-256：`9b697f65ecc2d9b0152f5ee96d72dde522a7827690349d9307935dacf40f42ec`。
- テスト用コンテナでインストーラーを起動し、7-Zip File Manager を起動できたら Tools → Benchmark を使う。インストーラーは Wine のコンテナ内にファイルを書き込む。GameNative 上でのインストーラー・インストール後の EXE 選択と測定は未検証。実行できなければそのまま失敗として記録する。
- FEX／Box64 を同じビルド・設定・スレッド数・辞書サイズで比較し、ウォームアップと各4回の結果を記録。CPU 使用と発熱が増えるので安全に中止できる状態で試す。これは圧縮負荷のベンチマークであり、ゲーム全体の FPS を直接示さない。
- Linux Wine の 7-Zip CLI での先行検査と Android 版変換器未検証の詳細は [命令変換ベンチマーク計画](命令変換ベンチマーク計画.md) を参照。今回の GUI インストーラー自体を GameNative で検査したわけではない。

## 描画：AIO Graphics Test 2.2.0

- [作者の公式リリース](https://github.com/The412Banner/AIO-Graphics-Test/releases/tag/2.2.0) の `AIO-Graphics-Test-64bit.exe`：4,295,721 バイト（約4.3 MB）。SHA-256：`5b5163850383c9cf3c011574be4fdc6000fd3c0961b9ed78f66bc09c1a06746d`。
- 作者は DX11・DX10・DX9 などと測定機能の対応を説明している。DX11 の固定時間測定は起動引数 `--cube dx11 --bench 15 --autoclose 5` を作者が案内している。GameNative 上の起動、引数、書き込み、DXVK／WineD3D、Pixel 9a の動作は**未確認**。測定ソフトの出力ができたら設定とともに保管する。結果は開始フォルダの `AIO Results/Benchmark/` に出力されると作者は説明している。
- 同じ解像度・同じ場面・設定でウォームアップ後、DXVK と WineD3D を各4回比較し、描画の欠落や失敗も記録する。小さな合成テストであり、実ゲームの映像や性能の証明にはならない。

## 安全と確認範囲

本機能のリンクは固定バージョンで、バージョン更新・ファイル検証は端末で自動実行しない。ダウンロードファイルのハッシュはユーザー側で検証できる。CI の一時領域で公式配布ファイルのハッシュと Windows x64 形式を検査するが、これは配布元の安全性、GameNative での起動や性能を保証しない。既存データを操作せず、署名違いで APK が上書きできない場合はアンインストールしない。

Pixel 9a の実 FPS、CPU スコア、熱・電力、LSFG 遅延、マルチタスクや Steam は未測定。エミュレーターの起動・描画確認を実機の測定結果として扱わない。
