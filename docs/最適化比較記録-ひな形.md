## 開始条件

1. ゲームデータ、既存 APK、キャッシュを勝手に消去しない。専用の試験環境を用意し、条件の変更を記録する。
2. 起動・描画の回帰試験とベンチマークの正しい結果を確認する。異常終了、出力不一致、読み込み未確認は成功として扱わない。
3. FEX の Linux キャッシュ有効時は現在正しく動作していないため、原因の解決と正確性・読み込みの再検証まで有効条件の性能比較を開始しない。Linux 版と Android 版は別々に検証する。
4. 温度や負荷の観測方法、休止・中止条件を開始前に決める。温度が取得できなければ未取得と記し、発熱の改善を主張しない。負荷が高すぎる場合は試験を中断する。
